   открытый редирект (только `#`-фрагмент).

- Включение: `registrationAllowed=true` **и** `OIDC_REGISTRATION_ENABLED=true`.
- `GET /api/v1/auth/register?returnUrl=...` → `302` на провайдера; `400` + `oidc_disabled`/

- После создания аккаунта — тот же `GET /api/v1/auth/callback`, сессионные cookie, автологин.

## [CURRENT_TASK]

Подготовить комплект тестовой документации на фичу **Registration** для `fullstack-next`.

1. **`README.md`** — назначение, границы (in/out of scope), окружения и как их поднять (включая
   переключение флагов), инструменты (браузер + DevTools, `curl`), критерии входа/выхода,
   приоритеты.
2. **`test-plan.md`** — стратегия (functional, configuration, negative, security, regression),
   риски (состояние realm, кэш браузера, разные домены), зависимости, метод фиксации дефектов.
3. **`test-cases.md`** — таблица `TC-REG-xxx`: ID, название, тип, приоритет, предусловия, шаги,
   ожидаемый результат, трассировка. Обязательно покрыть:
   - **Успешная регистрация (оба флага on):** кнопка видна → страница Keycloak → создание аккаунта →
     автологин, профиль виден, роль `user`.
   - **Комбинации флагов** (4 случая `registrationAllowed` × `OIDC_REGISTRATION_ENABLED`):
     `registrationEnabled` и поведение кнопки/эндпоинта; при выключенном — `400` с нужным кодом.
   - **`mode=none`:** регистрация недоступна, понятное сообщение.
   - **Негатив:** отмена на странице провайдера, `?authError=1`, неверные/незаполненные поля у
     провайдера, занятый username/email.
   - **Роль:** новый пользователь не имеет `admin`; admin-ресурсы недоступны; пользовательский
     доступ работает.
   - **Callback/домен:** после регистрации возврат на `user-kit.next.local`; cookie этого домена.
   - **Повторная регистрация** существующего пользователя — поведение провайдера (зафиксировать
     наблюдаемое, без выдумок).
4. **`security-checklist.md`** —
   - пароль не вводится и не обрабатывается приложением;
   - токены не в `localStorage`/`sessionStorage`/DOM/бандле;
   - небезопасные методы без `X-XSRF-TOKEN` отклоняются;
   - `returnUrl` не позволяет открытый редирект (только `#`-фрагмент);
   - cookie HttpOnly/`SameSite=Lax`/`Secure`;
   - регистрация не выдаёт `admin`.
5. **`configuration-matrix.md`** — таблица истинности двух флагов → `registrationEnabled` → видимость
   кнопки → ответ `/api/v1/auth/register`.
6. **`test-data.md`** — учётки/роли/состояния; значения переменных окружения для каждого режима.
7. **`traceability.md`** — матрица: каждый `FR-REG`/AC → `TC-REG`; пробелы явно помечены.
